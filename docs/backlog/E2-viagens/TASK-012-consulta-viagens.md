# TASK-012 — Consulta e detalhe de viagens

**Épico:** E2 — Operação e Acerto de Viagens · **Rastreabilidade:** RNF01 · **Depende de:** TASK-011

## Objetivo
Permitir localizar viagens rapidamente e visualizar todo o seu histórico em uma única tela.

## Escopo
- Listagem com filtros por status (Aberta, Fechada, Faturada, Cancelada), período, cliente, veículo e motorista.
- Tela de detalhe da viagem concentrando: dados de abertura, adiantamentos, despesas, remuneração, fechamento, acerto e fatura vinculada (seções preenchidas conforme as tarefas seguintes forem entregues).
- Atalhos para as ações disponíveis conforme o status (lançar despesa, fechar, acertar etc.).

## Critérios de aceite
- [ ] Os filtros retornam apenas as viagens correspondentes.
- [ ] O detalhe exibe os dados de abertura corretamente.
- [ ] As ações exibidas respeitam o status atual da viagem.
